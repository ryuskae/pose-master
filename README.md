# Pose Master

관절을 화면에서 직접 집어 고르는 대신 **상체/하체 → 부위 → 세부 관절** 순서로 선택하고, X·Y·Z 수치로 회전시키는 정적 3D 포즈 편집기입니다.

## 주요 기능

- 상체 5개, 하체 6개, 전신 3개로 나눈 조합형 포즈 프리셋
- 스쿼트, M자 다리 벌리기, 인어공주 자세, 네발 기기(all fours) 등 대표 자세
- Xbot의 기준 T포즈에 상대 회전을 합성해 프리셋이 골격의 초기 회전값을 덮어쓰지 않도록 처리
- 상체/하체와 팔·다리·몸통을 나눈 계층형 관절 선택 메뉴
- 프리셋·관절·인물·저장 탭으로 나눈 컴팩트한 사이드바
- 슬라이더와 숫자 입력을 동기화한 X·Y·Z 회전 조절
- 골반 위치 조절, 관절별 초기화, 전체 T포즈 초기화
- 화면의 +/− 및 ←/→/↑/↓ 버튼으로 카메라 확대·축소와 사방 이동
- 드래그 이동 범위를 인물 주변으로 제한하고 지면 아래 카메라 회전을 방지
- 기본형 Xbot 인물을 최대 6명까지 추가·선택·삭제
- 선택한 인물을 전후·좌우·상하(X·Y·Z)로 독립 이동
- 실제 관절 범위를 기준으로 모든 인물의 전신을 정면에 자동 맞춤
- 선택한 인물의 포즈를 브라우저에 저장·불러오기·덮어쓰기·삭제
- 3D 장면을 PNG로 촬영해 컴퓨터에 다운로드하거나 아이패드 공유 시트로 저장
- 현재 포즈를 JSON으로 복사
- 데스크톱·태블릿·모바일 반응형 UI

## 실행

별도의 빌드 과정이 없는 정적 앱입니다. 로컬 서버에서 `index.html`을 열면 됩니다.

```bash
python3 -m http.server 8080
```

브라우저에서 `http://localhost:8080`으로 접속하세요. Three.js와 Xbot 모델을 외부 CDN에서 불러오므로 인터넷 연결이 필요합니다.

## 좌표 규칙

- 회전값은 Xbot의 기준 T포즈에 더해지는 상대 각도(도)입니다.
- Y축은 위쪽이며, 골반 위치값은 미터 단위의 상대 이동량입니다.
- 앱에서 복사되는 JSON 형식은 `pose-master-v3`입니다.
